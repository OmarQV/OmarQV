## 🧪 Selected work

### 🔎 [Vector52](https://github.com/OmarQV/vector52)
**Evidence-first on-chain claim verification.** A forensic workflow designed to preserve raw blockchain evidence, calculate attributable flows and produce auditable conclusions with counter-evidence and explicit limitations.

`React` `TypeScript` `FastAPI` `Python` `Ethereum RPC` `The Graph` `Uniswap V3` `SHA-256`

> **Role:** Tech Lead · Frontend · Integration · Claim orchestration

<br/>

### ⚡ Pay-per-Thought
**Machine-to-machine micropayments for autonomous AI agents.** Experiments with agents paying other agents for work using x402-style payment flows and USDC settlement.

`Python` `LangGraph` `x402` `USDC` `EIP-712` `Smart Contracts`

[View hackathon project →](https://lablab.ai/ai-hackathons/nano-payments-arc/pay-per-thought)

<br/>

### 🌐 [AIni Pay](https://aini-pay.vercel.app/)
**Multichain payment experience combining Web3 and AI.** Built around wallet connectivity, EVM transactions and a simple cross-network user experience.

`React` `Vite` `Tailwind CSS` `Wagmi` `Viem` `WalletConnect` `Sonic` `Celestia`
